# Jarvis AI Assistant

Personal AI assistant powered by Clawdbot. A customizable, self-hosted AI assistant solution for individuals and businesses.

## Overview

Jarvis is a personal AI assistant built on the Clawdbot framework. It provides:
- Multi-channel communication (WhatsApp, Telegram, Discord, etc.)
- Customizable skills and tools
- Self-hosted privacy
- Cost-effective deployment using free AI models

## Repository Structure

```
├── apps/               # Application templates and demos
├── docs/               # Documentation
│   ├── business/       # Business models and strategies
│   └── technical/      # Technical guides and specifications
├── tools/              # Utility scripts and tools
├── scripts/            # Deployment and automation scripts
├── memory/             # Daily activity logs
├── configs/            # Configuration templates
└── gh-pages-demo/      # Static demo for GitHub Pages
```

## Quick Start

### For Live Demo (GitHub Pages)
Visit the live demo: [https://memepageextreme.github.io/Jarvis](https://memepageextreme.github.io/Jarvis)

### For Local Development
For deployment instructions, see [docs/technical/deployment.md](docs/technical/deployment.md)

### For GitHub Pages Deployment
1. Fork this repository
2. Go to Settings → Pages
3. Select "Deploy from a branch" → "main" → "/"
4. Visit `https://[your-username].github.io/Jarvis`
